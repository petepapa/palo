### Introduction

Icons are essential visual elements that help users understand and navigate your website. Palo integrates with Phosphor Icons, one of the most comprehensive and versatile icon libraries available.

Icons 是帮助用户理解和浏览网站的基本视觉元素。Palo 与 Phosphor Icons 集成，这是目前最全面、最通用的图标库之一。

Phosphor Icons offers:
- Thousands of icons in one unified family
- Multiple visual styles (stroke, fill, duotone)
- Various stroke weights
- Consistent and cohesive design

---

### Icon Set: Phosphor Icons

**Website**: [icon-sets.iconify.design/ph](https://icon-sets.iconify.design/ph/)

Phosphor Icons is a flexible icon family for interfaces, diagrams, presentations, and more.

Phosphor Icons 是一个灵活的图标系列，适用于界面、图表、演示等。

#### Styles Available

| Style | Description | When to Use |
|-------|-------------|-------------|
| **Regular** (默认) | Clean, balanced stroke weight | General purpose, UI elements |
| **Fill** | Solid filled icons | Emphasis, buttons, active states |
| **Bold** | Thicker strokes | Headings, large displays |
| **Thin** | Delicate strokes | Elegant designs, small sizes |
| **Light** | Light weight strokes | Modern, subtle designs |
| **Duotone** | Two-tone with color fills | Decorative, feature highlights |

#### Stroke Weights

| Weight | Stroke Size | Best For |
|--------|-------------|----------|
| Thin | 1px | Small icons, elegant designs |
| Light | 1.5px | Clean, modern interfaces |
| Regular | 2px | Default, balanced look |
| Bold | 2.5px | Emphasis, larger displays |
| Fill | N/A | Solid filled style |

### Icons Outside Phosphor (Brand & Regional)

Phosphor covers UI icons well, but **does not include every brand logo** — especially regional platforms like WeChat and Weibo. Palo ships a second icon set for these cases: **Font Awesome 6 Brands** (`fa6-brands`), loaded via [astro-icon](https://www.astroicon.dev/) and Iconify.

Phosphor 擅长 UI 图标，但**并不包含所有品牌 Logo**——尤其是微信、微博等区域平台。Palo 为此内置了第二套图标库：**Font Awesome 6 Brands**（`fa6-brands`），通过 astro-icon 和 Iconify 加载。

#### Already Used in Palo

These icons are live in the site today — same syntax everywhere:

以下图标已在站点中使用，语法完全一致：

| Platform | Icon name | Used in |
|----------|-----------|---------|
| WeChat / 微信 | `fa6-brands:weixin` | Footer launcher (`src/navigation.ts`), SocialShares (`src/shareConfig.ts`) |
| Weibo / 微博 | `fa6-brands:weibo` | SocialShares share bar |
| Douyin / 抖音 | `ph:tiktok-logo` | Footer launcher *(Phosphor — no separate Douyin glyph)* |
| GitHub | `ph:github-logo` | Navigation, Footer, SocialShares |
| YouTube | `ph:youtube-logo` | Footer launcher |

**Footer launcher example** (`src/navigation.ts`):

```typescript
{
  label: '*WeChat: *@pp71270371',
  icon: 'fa6-brands:weixin',
  type: 'qrCode',
  qrCode: '/branding/wechat.JPG',
},
{
  label: '*Douyin: *@petepa',
  icon: 'ph:tiktok-logo',
  type: 'qrCode',
  qrUrl: 'https://v.douyin.com/...',
},
```

**Social share bar example** (`src/shareConfig.ts`):

```typescript
{
  name: 'Weibo',
  icon: 'fa6-brands:weibo',
  actionType: 'link',
  buildUrl: ({ url, title }) =>
    `https://service.weibo.com/share/share.php?url=${encodeURIComponent(url)}&title=${encodeURIComponent(title)}`,
},
{
  name: 'WeChat',
  icon: 'fa6-brands:weixin',
  actionType: 'modal',
  modalId: 'palo-wechat-share-modal',
},
```

**In any Astro component or MDX:**

```astro
---
import { Icon } from 'astro-icon/components'
---

<Icon name="fa6-brands:weixin" size="24" aria-hidden="true" />
<Icon name="fa6-brands:weibo" size="24" aria-hidden="true" />
```

#### How to Register a New Icon Set

Palo currently bundles `ph` and `fa6-brands` in `astro.config.mjs`:

```js
icon({ include: { ph: ['*'], 'fa6-brands': ['*'] } })
```

To add another Iconify collection (e.g. `simple-icons`):

1. **Install** the JSON package:
   ```bash
   npm install @iconify-json/simple-icons
   ```
2. **Register** it in `astro.config.mjs`:
   ```js
   icon({ include: { ph: ['*'], 'fa6-brands': ['*'], 'simple-icons': ['*'] } })
   ```
3. **Use** with the same `<Icon>` component:
   ```astro
   <Icon name="simple-icons:github" size="24" />
   ```

Browse all Iconify sets at [icon-sets.iconify.design](https://icon-sets.iconify.design/) — prefix the icon name with the set ID (e.g. `fa6-brands:weibo`, `ph:heart`).

### How to Use Icons in Palo

#### Basic Usage

```astro
---
import { Icon } from 'astro-icon/components'
---

<!-- Basic icon -->
<Icon name="ph:house" />

<!-- With size -->
<Icon name="ph:github-logo" size="24" />

<!-- Brand icon outside Phosphor -->
<Icon name="fa6-brands:weixin" size="24" />

<!-- With custom color -->
<Icon name="ph:youtube-logo" size="48" class="text-red-500" />
```

#### Using Different Styles

```astro
<Icon name="ph:heart" size="48" />
<Icon name="ph:heart-fill" size="48" />
<Icon name="ph:heart-bold" size="48" />
<Icon name="ph:heart-thin" size="48" />
<Icon name="ph:heart-light" size="48" />
<Icon name="ph:heart-duotone" size="48" />
```

#### Using in Navigation

Add icons to navigation items in `src/navigation.ts`:

```typescript
{
  label: 'GitHub',
  href: 'https://github.com/your-username',
  icon: 'ph:github-logo',
},
{
  label: 'WeChat',
  icon: 'fa6-brands:weixin',
  type: 'qrCode',
  qrCode: '/branding/wechat.JPG',
},
```

#### Using in Components

```astro
<button>
  <Icon name="ph:magnifying-glass" size="20" />
  Search
</button>

<div class="flex items-center gap-2">
  <Icon name="ph:envelope" size="24" />
  <span>contact@example.com</span>
</div>
```

### Tips

1. **Consistency**: Use the same icon style throughout your site
2. **Size Matters**: Match icon sizes to text sizes for visual harmony
3. **Accessibility**: Always include text labels or ARIA descriptions for screen readers
4. **Color**: Use Tailwind classes like `text-primary` for easy color customization
5. **Brand icons**: Reach for `fa6-brands:` when Phosphor has no logo — check [icon-sets.iconify.design](https://icon-sets.iconify.design/) first

1. **一致性**：在整个网站中使用相同的图标风格
2. **尺寸**：将图标尺寸与文字尺寸匹配以获得视觉和谐
3. **无障碍**：始终为屏幕阅读器添加文字标签或 ARIA 描述
4. **颜色**：使用 Tailwind 类如 `text-primary` 以便轻松自定义颜色
5. **品牌图标**：Phosphor 没有 Logo 时使用 `fa6-brands:` — 先在 Iconify 搜索
