### Introduction

The BreakoutImage component is a powerful tool for creating visually stunning image layouts in your content. It allows images to break out of the normal container constraints, creating dramatic full-width or wide displays that capture attention and enhance the visual impact of your articles.

This component provides three distinct layout modes that give you precise control over how images appear relative to the content container, from edge-to-edge full width to contained within the normal flow.

BreakoutImage 组件是一个用于在内容中创建视觉震撼的图片布局的强大工具。它允许图片突破正常容器的限制，创建戏剧性的全宽或宽幅显示，捕捉注意力并增强文章的视觉冲击力。

该组件提供三种不同的布局模式，让您可以精确控制图片相对于内容容器的显示方式，从边缘到边缘的全宽显示到保持在正常流中的容器内显示。

---

### What is BreakoutImage Component?

The BreakoutImage component is designed to display landscape images with flexible width control. It solves the common problem of images being constrained by container margins, allowing for more dramatic visual presentations.

Core features include:
- Three layout modes: full, wide, and contained
- Automatic responsive behavior
- Consistent border radius handling
- Accessibility support with alt text and decorative options
- Shadow overlay for visual depth

BreakoutImage 组件旨在显示具有灵活宽度控制的横向图片。它解决了图片受容器边距限制的常见问题，允许更戏剧化的视觉展示。

核心功能包括：
- 三种布局模式：full、wide 和 contained
- 自动响应式行为
- 一致的圆角处理
- 带 alt 文本和无障碍支持的装饰选项
- 用于视觉深度的阴影叠加

### Layout Modes

#### Full Layout

The `full` layout expands the image left and right to touch the screen edges, creating a dramatic edge-to-edge display. This layout forces sharp/straight corners (no border radius) to create a bold, modern look.

The `full` 布局将图片向左向右扩展到屏幕边缘，创建戏剧性的边缘到边缘显示。此布局强制使用直角（无圆角）来创造大胆、现代的外观。

**Example**:
```mdx
<BreakoutImage
  src="/posts/post-image-1.jpg"
  alt="Full width landscape photo"
  layout="full"
/>
```

#### Wide Layout

The `wide` layout expands the image left and right but leaves a small gap to the screen edges, maintaining a more refined appearance while still breaking out of the normal container. This layout retains rounded corners for a softer, more approachable feel.

The `wide` 布局将图片向左向右扩展，但保留与屏幕边缘的小间隙，在保持更精致外观的同时仍然突破正常容器。此布局保留圆角，营造更柔和、更平易近人的感觉。

**Example**:
```mdx
<BreakoutImage
  src="/posts/post-image-2.jpg"
  alt="Wide layout landscape photo"
  layout="wide"
/>
```

**Demo**:

#### Contained Layout

The `contained` layout keeps the image within the normal container, maintaining the same margins as other content elements. This layout is ideal for images that should blend naturally with the text flow while still providing visual interest.

The `contained` 布局将图片保持在正常容器内，与其他内容元素保持相同的边距。此布局非常适合应该与文本流自然融合的图片，同时提供视觉趣味。

**Example**:
```mdx
<BreakoutImage
  src="/posts/post-image-3.jpg"
  alt="Contained landscape photo"
  layout="contained"
/>
```

### Core Parameters

#### `src`
- **Type**: `string`
- **Required**: `true`
- **Default**: `none`
- **Function**: The path to the image file

图片文件的路径

**Example**:
```yaml
src: /posts/post-image-1.jpg
```

---

#### `layout`
- **Type**: `'full' | 'wide' | 'contained'`
- **Required**: `false`
- **Default**: `'full'`
- **Function**: The layout style of the image

图片的布局样式

- `'full'`: Expands to screen edges with sharp corners
- `'wide'`: Expands with small edge gaps, retaining rounded corners
- `'contained'`: Stays within normal container

**Example**:
```yaml
layout: full
```

---

#### `alt`
- **Type**: `string`
- **Required**: `true` (if not decorative)
- **Default**: `''`
- **Function**: Alt text for screen readers

屏幕阅读器的替代文本

**Example**:
```yaml
alt: "A beautiful mountain landscape at sunset"
```

---

#### `decorative`
- **Type**: `boolean`
- **Required**: `false`
- **Default**: `false`
- **Function**: Set to true if image is purely decorative

设置为 true 如果图片仅用于装饰

When an image is decorative, it should have empty alt text (`alt=""`), and this parameter ensures proper accessibility handling.

当图片是装饰性的时，应该使用空的 alt 文本（`alt=""`），此参数确保正确的无障碍处理。

**Example**:
```yaml
decorative: true
```

### Backward Compatibility

The component supports a deprecated `fullWidth` parameter for backward compatibility with older code:

该组件支持已弃用的 `fullWidth` 参数，以保持与旧代码的向后兼容性：

- `fullWidth={true}` is equivalent to `layout="full"`
- `fullWidth={false}` is equivalent to `layout="contained"`

### Accessibility Features

The BreakoutImage component is built with accessibility in mind:

- **Alt text support**: Properly describes images for screen readers
- **Decorative mode**: Purely visual images can be marked as decorative
- **Semantic markup**: Uses appropriate HTML elements
- **Color contrast**: Works with the existing color system

BreakoutImage 组件以无障碍为核心构建：

- **替代文本支持**：为屏幕阅读器正确描述图片
- **装饰模式**：纯视觉图片可以标记为装饰性
- **语义化标记**：使用适当的 HTML 元素
- **颜色对比**：与现有颜色系统配合使用

### Pro Tips

1. **Use full layout sparingly**: Save it for hero images or key visual moments to maintain impact
2. **Match layout to content**: Use contained for supporting images, wide for secondary visuals
3. **Consider mobile experience**: Full layout can be very effective on mobile where edge-to-edge images feel immersive
4. **Maintain aspect ratio**: BreakoutImage works best with landscape-oriented images (16:9 recommended)
5. **Combine with PostHeader**: Use different layouts throughout a post for visual variety

1. **谨慎使用 full 布局**：将其用于英雄图像或关键视觉时刻以保持冲击力
2. **根据内容匹配布局**：将 contained 用于辅助图片，wide 用于次要视觉
3. **考虑移动端体验**：full 布局在移动端可以非常有效，边缘到边缘的图片感觉身临其境
4. **保持宽高比**：BreakoutImage 最适合横向图片（建议 16:9）
5. **与 PostHeader 结合使用**：在整个帖子中使用不同的布局以增加视觉多样性
